# PDF2CBZ — конвертер PDF в CBZ

Конвертер PDF в CBZ для читалок комиксов и манги: выбрал файлы → нажал
«Конвертировать» → получил готовые `.cbz`. Пара к десктопному
[PDF2CBZ (C# / WPF)](https://github.com/SaymonRen-ui/pdf2cbz).

Готовится к публикации в RuStore.

## Возможности

- Очередь PDF-файлов (выбор или «Поделиться» из других приложений)
- Качество JPEG 1–100, чёткость DPI 100/150/200/300
- Аккуратные имена страниц, архив без сжатия (Store) — читалки открывают мгновенно
- Ошибка одного файла не останавливает очередь, статусы и ETA
- Фоновый режим: уведомление с прогрессом и отменой
- Вывод в «Загрузки» или в свою папку (запоминается)
- Тёмная/светлая тема (или как в системе)
- Одна реклама после кнопки «Конвертировать», конвертация идёт параллельно

## Сборка

Открыть папку в Android Studio и нажать Run, либо из командной строки:

```
.\gradlew.bat :app:assembleDebug      # отладка
.\gradlew.bat :app:assembleRelease    # релиз (нужен ключ, см. ниже)
.\gradlew.bat :app:bundleRelease      # AAB для стора
```

Требования: JDK 17, Android SDK (compileSdk 36, minSdk 26).

### Релизная подпись

Ключ `pdf2cbz-release.jks` и пароли в `local.properties` не коммитятся
(см. `.gitignore`). Потеря ключа = невозможность обновлять приложение в сторе,
бэкап обязателен.

## Монетизация

Один interstitial РСЯ после кнопки «Конвертировать» (очередь идёт параллельно).
ID блока — `core/ads/AdManager.kt` (`AD_UNIT_ID`).

Важно: сервер РСЯ не отдаёт рекламу дебажным сборкам — проверять показ
только на релизе.

## Конфиденциальность

Файлы обрабатываются только на устройстве и никуда не отправляются.
Подробности: [PRIVACY.md](PRIVACY.md).
